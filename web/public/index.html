BAĞLANIYOR

Yapay zekâ ekle (tek adım)

1) Sağlayıcıyı seç. 2) API anahtarını aşağıdaki kutuya yapıştır. 3) Ekle'ye bas. Anahtarı sağlayıcının sitesinden alırsın (Grok: console.x.ai, ChatGPT: platform.openai.com, Claude: console.anthropic.com). Anahtar bu bilgisayarda saklanır ve bir daha gösterilmez.

Gelişmiş: kendi ajan tokenını oluştur

Ajan ekle

Yalnızca kullanıcı tokenı ile görünür. Token bir kez gösterilir. ChatGPT/Gemini web sohbetleri yerel Hub'a bağlanamaz; çalışan yol API hesabı + worker'dır.

Mesaj gönder

Görev oluştur

Görevi yalnızca claude1 veya user oluşturabilir.

Backend Bağlanıyor…

Salt okunur görünüm. Backend'in kendi tokenı vardır (data/backend_token.txt); Hub tokenından farklıdır. Kurulu uygulamada otomatik gelir. Elle çalıştırıyorsan buraya yapıştır. Üstteki Hatırla kutusu (Ayarlar) bu token için de geçerlidir.

Onaylar Bağlanıyor…

Ajanların istediği riskli eylemleri (silme, kurulum, push…) yalnızca sen onaylarsın. Bunun için kullanıcı tokenı gerekir. Kurulu uygulamada otomatik gelir ve yalnızca bellekte durur. Tarayıcıda elle açtıysan: token'ı yazdığın yer bellektir, girince alandan silinir, 5 dakika işlem yapmazsan veya sayfayı yenilersen unutulur. Token'ı girmeden bekleyen istekleri yalnızca görürsün (Backend sekmesindeki token ile).

Onay token'ı yok: yalnızca görüntüleme

Yapay zeka hesapları Bağlanıyor…

Sağlayıcıları herkes görür. Hesap ekleme, silme, açıp kapatma ve test yalnızca kullanıcı tokenı ile yapılır (Onaylar sekmesindeki aynı token). API anahtarı hiçbir yerde saklanmaz, gönderilince formdan silinir ve geri gösterilmez.

Onay token'ı yok: yalnızca görüntüleme

Hesap ekle

Herhangi bir OpenAI uyumlu uç nokta olur (Ollama, LM Studio, OpenRouter, OpenAI…). local: yalnızca bu bilgisayarın adresi (127.0.0.1 / localhost), anahtar isteğe bağlı. cloud: yalnızca https ve anahtar zorunlu; kullanımı günlük bütçeye sayılır.

AYARLAR

Kurulu uygulamada (WACC-Setup.exe) token'lar kendiliğinden gelir: burada hiçbir şey yapman gerekmez. Bu kutu yalnızca paneli tarayıcıda elle açıyorsan lazım.

SES
